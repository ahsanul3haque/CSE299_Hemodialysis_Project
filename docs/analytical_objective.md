Analytical Objective:

The objective of this project is to develop a prescriptive early-warning machine learning system that predicts the onset of Intradialytic Hypotension (IDH). 
To function as a genuine early-warning tool, the model is strictly constrained to processing baseline pre-dialysis vitals and machine settings recorded prior to treatment initiation (Hour 0). 
Furthermore, the system transitions from standard predictive classification to Prescriptive Analytics by utilizing Diverse Counterfactual Explanations (DiCE). 
This allows the tool to not only predict crash risk but also recommend minimal, actionable adjustments to mutable clinical levers (such as dialysate temperature or ultrafiltration rate) to prevent the adverse event. 
Because IDH represents a minority class, the model’s performance is evaluated strictly on Precision-Recall Area Under Curve (PR-AUC) and Recall.
